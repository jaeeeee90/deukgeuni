# 득근이 운동 종목 관리 고도화 설계

## 목표
기존 기록을 보존하면서 다중 자극 부위, 약 80종의 운동 마스터, 카테고리별 최근 운동, 검색, 방 범위 사용자 운동, 네 가지 기록 방식을 제공한다.

## 카탈로그
- 카테고리는 전체·가슴·등·하체·어깨·팔·복근·코어·유산소다.
- 마스터 운동은 `{id, name, categories, recordingMethod}`를 사용한다. 기존 21개 ID는 그대로 유지한다.
- 하나의 운동은 여러 `categories`에 속할 수 있다.
- 기본 종목은 약 80개이며, 국내 헬스장 표기와 고유·안정 ID를 사용한다.

## 저장 호환성
- 기존 `deukgeuni:workout-demo:v1`을 읽을 때 유효한 v1 상태만 메모리에서 v2로 변환한다.
- v1의 `{weight, reps}` 세트는 `recordingMethod: 'weight-reps'` 세트로 보존한다.
- v2에는 `customExercises`, `nextRecordOrder`와 세트별 `recordingMethod`, `recordedOrder`가 추가된다.
- v1 변환 및 v2 검증이 모두 성공한 뒤에만 v2를 저장한다.
- JSON 해석·v1 변환·v2 검증 오류는 기존 키를 덮어쓰지 않는다. 화면에 보호 안내를 보여 준다.
- 새 사용자 운동은 v2의 `customExercises`에 `{id, roomId, name, categories, recordingMethod}`로 저장한다. 방 삭제 시 함께 정리한다.

## 최근 운동
- 현재 사용자 세트만 대상으로 한다.
- 선택 카테고리에 속하는 운동만 후보로 하며, 전체는 모든 운동을 후보로 한다.
- `entry.date`(실제 수행 날짜)를 내림차순으로 우선하고, 같은 날짜는 세트의 `recordedOrder` 내림차순으로 정렬한다.
- 운동별 최신 세트 하나만 남긴 뒤 상위 3개를 최근 운동으로 표시한다.
- 나머지 운동은 한국어 가나다순으로 표시하며 최근 목록과 중복하지 않는다.

## 기록 방식
- `weight-reps`: 0 이상 kg과 1 이상 정수 회
- `reps`: 1 이상 정수 회
- `duration`: 1 이상 초 또는 분
- `duration-distance`: 1 이상 분과 0 이상 km
- 기존 무게·횟수 표시와 수정 기능은 그대로 유지한다.

## UI
- 종목 선택 바텀시트에 검색창, 전체 포함 카테고리, 최근 운동 영역, 직접 등록 안내를 둔다.
- 검색 결과가 없을 때 이름·복수 부위·기록 방식을 입력하는 등록 폼을 표시한다.
- 사용자 운동은 현재 방에서만 선택 가능하며, 같은 방에서 이름을 정규화해 중복을 막는다.
- 기존 아이보리·파스텔·코랄 모바일 디자인을 유지한다.

## 제외 범위
Supabase, 로그인, QR·친구 초대, 실시간 동기화, 통계, 외부 이미지 업로드는 구현하지 않는다.
